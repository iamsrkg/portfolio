Flagship · Backend · 2026

Secure Multi-Tenant Task Management API

A production-style REST API in which every user sees only the projects and tasks they own or are assigned to. Built to show the patterns real services need: tenant isolation, safe concurrent writes and consistent error handling.

  • Stateless JWT auth with RBAC through method-level security
  • Optimistic locking (JPA @Version) that returns 409 Conflict on concurrent edits
  • Global exception handling and a uniform response envelope, with no stack traces leaked
  • Pagination, sorting and status filtering. Multi-stage Docker build with Compose
